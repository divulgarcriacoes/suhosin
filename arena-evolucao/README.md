# Arena Evolução

Protótipo (dados fictícios) de app para escola de futebol com várias unidades:
painel, presença, mensalidades, avisos por push/SMS, alunos, carta de overall (estilo EA FC), visão dos pais e ideias.

- `index.html`: página única, abre direto no navegador (fotos e logo embutidos).
- Artifact publicado: https://claude.ai/artifact/YVZTDnmXYHoBDAENThyCBA
