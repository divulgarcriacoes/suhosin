# Legendas por rede social

Use `--linkedin` ou `--redes linkedin facebook whatsapp pinterest tiktok google`.
Cada produto ganha, ao lado de `legenda.txt` (Instagram), um `legenda_<rede>.txt` pronto para colar.
Os modelos ficam nesta pasta (`linkedin.txt`, `facebook.txt`...): edite o texto à vontade.
Campos: {nome} {codigo} {preco} {minimo} {gravacao} {categoria} {link} {whatsapp} {hashtags} {hashtags3}.
Linha cujo campo esteja vazio some sozinha.

Imagens: feed.jpg serve para LinkedIn, Facebook, Pinterest e Google; story.jpg para Status do WhatsApp;
video.mp4 (com --colecao) para TikTok e YouTube Shorts.
